时间线 · 关于

AI 资讯时间线 首先是给机器读的。下面五个地址随引擎每轮更新，直接 curl 即可， 不需要 key、不需要 UA 伪装。接口一旦公布就不破坏：只增字段，要改就开 /api/v2/。

五个地址

地址是什么格式
/api/v1/latest.json 精选 + 24h 全量，三语标题 / 一句话 / 为什么重要，含抢跑时长与多源簇JSON
/api/v1/sources.json 信源登记表：我们接了哪些源、哪些待接，以及与对标清单的当日差别JSON
/api/v1/heartbeat.json 引擎心跳：上轮何时跑、成功与否、出了几条精选（判新鲜度看它）JSON
/feed.xml RSS 2.0，中文标题 + 原文链接，三语摘要在 content:encodedXML
/llms.txt 本页的机器版：字段说明与取数口径Markdown

一行接入

Claude Code / Codex / Cursor 里直接让它去读：

把 https://news.aiimmigrant.de/api/v1/latest.json 拉下来，按 selected 挑今天值得看的 AI 新闻，
每条给我中文一句话 + 原文链接，再说说为什么重要（字段 why_it_matters.zh）。

命令行：

curl -s https://news.aiimmigrant.de/api/v1/latest.json | jq '.selected[] | {title: .title.zh, url, why: .why_it_matters.zh}'
curl -s https://news.aiimmigrant.de/api/v1/heartbeat.json | jq '{when, status, selected}'
curl -s https://news.aiimmigrant.de/feed.xml | head -40

MCP / RSS 阅读器：把 https://news.aiimmigrant.de/feed.xml 加进订阅即可， <category>精选</category> 是我们当轮挑出来的那几条。

字段口径

字段含义
title.{zh,en,de} / one_liner.* / why_it_matters.* 三语标题、一句话摘要、为什么重要。AI 生成，可能有误。
quote_en英文原文引句，用来核对我们有没有写歪。
scoop_hours我们比同题报道早多少小时发现；负数表示落后。
n_sources / also_reported_by同一事件有几家在报、分别是谁。
published_utc / first_seen_utc原文发布时间 / 我们首次捕获时间，均为 UTC。
source.tier信源等级：T1 一手官方 / T2 专业媒体 / T3 聚合。

更新频率与许可

精选库随引擎轮次更新（常态每小时一轮，launchd :07）；2026-09-22 起为控预算暂停定时器，当前人工触发，恢复定时后本说明同步。接口无鉴权、无频控，请自觉别超过 1 次/分钟。

摘要、标题翻译与点评由本站 AI 生成，可自由取用（署名 news.aiimmigrant.de 即可）；原文版权归各信源所有，请始终带上 url 回链原文。
